# 山線之間｜臺三線生態博物館

十二聚落的一頁式靜態策展展示。開啟 `index.html` 即可使用，無需安裝、建置或後端。

## 展示內容

- 龍潭、關西、新埔、竹東、北埔、峨眉、三灣、南庄、獅潭、公館出磺坑、大湖、東勢・大茅埔。
- 48 段地方故事、48 個依站點與角色切換的預寫策展問題，以及來源摘要與連結。
- 原創 SVG 山城插畫與鍵盤／滑鼠選站，桌機與手機版面。
- 所有故事在 HTML 中；停用 JavaScript 仍可讀完 12 站。

## 無付費服務

此版本沒有登入、即時 AI、翻譯、語音合成、追蹤程式、外部字型或 CDN。
所有 CSS、JavaScript、資料和圖像均內嵌。CSP 的 `connect-src 'none'` 禁止背景資料連線。
角色問答是預寫策展內容，不是生成式 AI；只有使用者點選來源連結，才會開啟外部官方網站。
沒有任何 API key、伺服器環境檔、舊站後端或部署識別資訊。

## 資料與界線

資料核對日期為 2026-10-24，32 個官方來源的核對層級隨故事列出，部分僅由官方搜尋摘述支持。
2018-02-22 政策文件只作歷史背景，不代表今日施工、開放或成果。
新埔、南庄、公館出磺坑與大茅埔標示廊帶延伸支線；圖像不是等比例道路圖或精確建築復原。
南庄等地的多元文化不一概稱為客家。虛構角色不代言真實居民、作家或部落。
預寫內容區分來源摘要與策展提問，沒有假造訪談；大茅埔相關水圳名稱的不確定性明示保留。

## 本地驗證

Chromium 桌面 1440×1000、手機尺寸 390×844：站點與四角色切換、來源顯示、無水平溢出通過。
完整操作記錄沒有任何外部背景請求或 API 請求，沒有瀏覽器程式錯誤；停用 JavaScript 時 12 站均可見。
未宣稱實體 iPhone 或所有瀏覽器均已測試。

## GitHub Pages

可在儲存庫 Settings → Pages 選擇 Deploy from a branch，使用 `main` 的 `/ (root)`。
不需要 Actions、Secrets、付費服務或額外建置。只有 GitHub 完成 Pages 發布後，展示網址才算啟用；儲存庫網址不是展示網址。

## 使用與來源

程式化插畫與網站程式為本專案製作；地方資料以原創摘要呈現，引用連結的著作權仍屬各來源。
